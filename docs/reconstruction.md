# REA 관찰과 재구성

분석일: 2026-11-14
대상: https://sbtglobal.com/ → /kor/index.php

REA capture_browser_scenario로 Chromium을 새 임시 프로필로 실행하고 페이지 로딩을 기다린 뒤 DOM, 접근성 트리, 스크린샷을 관찰했다.

관찰 Evidence: ev_e55fb6eb0abde87bbf9a8a45cdae5690c18ccb161e0a178e0ee9f94b39db480e

관찰한 메인 구성: 상단 가로 내비게이션, 밝은 추상형 배경, 좌측 대형 제목, 우측 SAP/DX 서비스 카드, 회사 소개 및 실적 수치, 솔루션 탭/슬라이드, 프로젝트 및 문의 CTA, 회사 연락처 푸터. 초기 로딩 오버레이와 광고 팝업도 관찰했다.

THIT에 적용한 구성: 동일한 메인 정보 흐름을 바탕으로 블루와 네이비, 첨부 로고, 문서의 슬로건을 적용했다. 원본 실적 수치는 근거가 없어 핵심 가치 네 가지로 대체했고 SAP/DX는 THIT의 실제 사업으로 교체했다. AI는 확장 계획으로 표시했다. 서비스 탭과 상세 창, 슬라이드 제어, 반응형 메뉴, 이메일 작성 기능을 구현했다.

범위와 한계: 공개 메인 페이지의 한 시점 관찰이다. 원본의 백엔드와 비공개 기능 및 전체 하위 페이지를 복제하지 않았다. 추상 그래픽은 CSS로 새로 제작했고 원본 회사의 그래픽·문구·고객사·성과 수치를 가져오지 않았다. 현재 문의 기능은 이메일 클라이언트 연동이며 별도 접수 서버는 없다.

검증: npm run build 통과. REA로 로컬 데스크톱 화면을 캡처했고 page-errors 이벤트는 0건이었다.

모바일 검증: REA의 복수 액션 시나리오 응답이 지연되어 로컬 Playwright/Chromium으로 390×844 화면을 추가 검증했다. 가로 넘침 없음, 모바일 메뉴 열기와 서비스 이동, 운영 서비스 탭 선택, 상세 창 표시 및 Escape 닫기 정상, pageerror 0건. 문의 이메일은 실제 발송하지 않았다.

## 모션 및 내비게이션 개선

원본 공개 `/js/main.js`와 `/css/main.css`를 추가 확인했다. 원본에는 글자별 순차 등장, 스크롤 기반 강조색 채움, 카드 순차 등장, 고정 섹션 안의 그래픽 조합 전환 등이 있었다. 이번 변경에서는 이를 참고해 THIT용 제목 마스킹/글자 등장, 관성 포인터 패럴랙스, 스크롤 연동 배경/문장 강조, IntersectionObserver 기반 섹션 순차 등장, 서비스/모달 전환을 새로 구현했다. 원본의 GSAP 소스나 라이선스가 필요한 플러그인은 복사하지 않았다.

서비스 그림은 독립 SVG 컴포넌트로 제작해 레이어 부유, 궤도 회전, 신호 점멸을 적용했다. 슬라이드 진행률은 실제 재생 시간과 연결되며 일시정지를 제공한다. reduced-motion 설정에서는 자동 전환과 장식 애니메이션을 멈추고 내용을 즉시 표시한다. 스크롤 이벤트는 requestAnimationFrame으로 묶고 Observer와 이벤트는 컴포넌트 해제 시 정리한다.

계층 메뉴: Company(소개/브랜드 의미/가치), Services(개발/운영/인력), AI Consulting(방향/단계/과제), Our Approach(방식), Contact(상담/연락처). 데스크톱 드롭다운과 모바일 아코디언을 제공한다. 서비스 하위 메뉴는 섹션 이동과 해당 탭 선택을 함께 수행한다. 접힌 드롭다운은 inert로 키보드 접근에서 제외하며 서비스 탭은 방향키/Home/End로 선택할 수 있다.

검증: Chromium 데스크톱/모바일 메뉴 이동과 서비스 선택, 상세 창 및 Escape 닫기, 가로 넘침 없음, reduced-motion 시 애니메이션 중지, pageerror 0건 확인. npm run build 통과.

## 대메뉴별 페이지 분리

한 화면의 섹션을 홈과 Company / Services / AI Consulting / Our Approach / Contact의 독립 페이지로 분리했다. GitHub Pages가 각 디렉터리의 index.html을 직접 제공하도록 Vite의 다중 진입점 빌드를 구성했으며 공통 헤더/푸터/모달과 모션을 유지했다. 대메뉴 링크와 별도 펼침 버튼, 현재 페이지 표시, 페이지 내 메뉴와 브레드크럼을 제공한다. 서비스 선택은 URL 쿼리로 유지하며 미션·비전, 수행 범위, AI 도입 단계·산출물·원칙은 기존 브랜드 문서 데이터에서 가져왔다.

검증: Pages와 동일한 /THIT_HOMEPAGE/ 경로의 프로덕션 미리보기에서 여섯 경로 HTTP 200, 페이지별 단일 h1, 다른 대메뉴 본문의 분리, 로고 정상 로딩, 대메뉴 이동/하위 항목 직접 연결, 서비스 URL 선택/방향키/새로고침, 모바일 모든 내부 페이지 직접 접속/새로고침과 가로 넘침 없음, 빈 문의 폼 유효성 검사 및 pageerror 0건 확인. 실제 발송은 하지 않았다.
